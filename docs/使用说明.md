# 使用說明

## 快速開始

1. 把 `SongRequestMod.dll` 放進遊戲的 `Mods` 資料夾（需要 [MelonLoader](https://melonwiki.xyz/) 0.6.x，Mono 版本）
2. 開遊戲，等遊戲資料載入完成
3. 電腦瀏覽器打開 `http://127.0.0.1:8790/` 就能點歌
4. 同一個網路的手機：把 `127.0.0.1` 換成日誌裡「手機(同網)」那個位址（例如 `192.168.3.2:8790`）
5. 要給不在同一個網路的人點歌：本機網頁會自動彈出「遠端分享」面板，複製任一條連結發給對方（見[五、遠端分享](#五遠端分享)）

只要一個 dll，網頁、別名庫都包在裡面，不需要 Python 或其他程式。

---

## 一、安裝

| 檔案 | 放哪 | 必要 |
|---|---|---|
| `SongRequestMod.dll` | `<遊戲目錄>\Mods\`（例如 `H:\SDEZ1.70\Package\Mods\`） | 必要 |
| `page.html` | `<遊戲目錄>\Mods\SongRequestMod\page.html` | 不用。想自己改網頁時才放，放了會優先用這份，改完重新整理瀏覽器就生效 |
| `aliases.txt` | `<遊戲目錄>\Mods\SongRequestMod\aliases.txt` | 不用。想自己加別名時才放（見[四、別名](#四別名搜尋)） |
| `SongRequestMod.toml` | `<遊戲目錄>\`（放遊戲主程式的那層） | 第一次啟動會自動產生 |

裝好重開遊戲，MelonLoader 日誌會出現：

```
[SongRequest] v1.1.11.0 點歌台: http://127.0.0.1:8790/    手機(同網): http://192.168.3.2:8790/
```

遊戲資料載入完之前，網頁會顯示「遊戲資料載入中」並自動重試，不用手動重新整理。

> 日誌預設只顯示上面這行、分享連結和錯誤。要排查問題就在設定檔打開 `详细日志=true`。

## 二、網頁怎麼用

### 搜尋

- 曲名 / 藝術家 / 曲目 ID / 別名一起搜，空格分隔多個關鍵詞（每個都要符合），不分大小寫和全半形
- **簡體、繁體、日文字形通用**：搜「樱」「櫻」「桜」都找得到同一首，曲名、藝術家、別名都適用
- 搜到的是別名時，該行會標出命中的別名

### 篩選與排序

| 項目 | 說明 |
|---|---|
| 難度 | 全部 / BAS / ADV / EXP / MAS / Re:M。選了某個難度，等級篩選和排序就只看那個難度 |
| 譜面 | 全部 / DX / 標準 |
| 等級 / 定數 | 兩種寫法通用，可以混用（見下表）。上下限填反會自動對調，看不懂的輸入會標紅 |
| 分類 | 遊戲裡的分類 |
| 排序 | ID 升序 / 曲名 / 定數 ↓ / 定數 ↑ |

等級 / 定數的寫法：

| 輸入 | 意思 |
|---|---|
| `13` | 等級 13，也就是定數 13.0～13.6 |
| `13+` | 等級 13+，也就是定數 13.7～13.9 |
| `13.4` | 定數 13.4 |
| 例：`12` ～ `13.4` | 定數 12.0～13.4 |

沒選難度時，只要有任一個能玩的難度落在範圍內就會列出來。

### 點歌

- 每首歌右邊有 5 個難度塊（BASIC～Re:MASTER），上面是**定數**（如 13.7），滑鼠移上去會顯示「等級 · 定數」
- **點難度塊 = 點這首歌的這個難度**
- 同時有 DX 和標準譜的歌會分成兩行，**點哪一行就跳哪一種譜面**；點歌結果會寫出 `DX` 或 `STD`
- 這個版本玩不了的難度（遊戲判斷沒有這個譜面）會變灰、不能點

### 鍵盤

| 按鍵 | 作用 |
|---|---|
| `/` | 跳到搜尋框 |
| `Esc` | 清空搜尋 |
| `↑` `↓` | 移動高亮的曲目 |
| `Enter` | 點高亮的那首（在搜尋框裡按 = 點搜尋結果第一首） |
| `R` | 隨機點一首（有選難度就隨機點那個難度） |

### 其他

- **正在遊玩面板**（右側）：曲名、難度、Combo、分數、判定（CRITICAL PERFECT / PERFECT / GREAT / GOOD / MISS）、Life，即時更新
- **曲庫自動同步**：遊戲曲庫變了（熱匯入新歌等）網頁會自動重新讀取，搜尋詞和篩選不會被清掉。也可以按「重新整理曲庫」強制重讀
- **封面**：直接從遊戲資源取圖，自製譜也有

## 三、點歌的行為

- **要在選曲畫面才能跳**。正在打歌、標題畫面、切換畫面途中時，會回覆原因（例如「目前不在選曲介面」）。遊戲正在播換畫面動畫時會先等最多 3 秒
- 點了之後，遊戲會**跳到那首歌、自動進難度選擇畫面、游標停在你點的難度**，接著按機台開始鍵就行
- 已經在難度選擇畫面時點歌，會先正確退回選曲列表再跳，之後按返回不會卡住
- 那首歌沒有你點的難度時，會退到能玩的最高難度，並在回覆裡寫出實際選了哪個
- 連續快速點很多首，只會執行最後一首，前面的不算失敗
- 不會跳進對戰、挑戰、段位、聯機等特殊分類（這種歌會提示你在遊戲裡手動選）

## 四、別名搜尋

mod 內建一份別名庫（約 1400 首、10000 多條，含中文暱稱、羅馬拼音、英文縮寫），資料來自 MuNET 別名資料庫。

想自己加別名：在 `Mods\SongRequestMod\` 放一份 `aliases.txt`，**用 Tab 分隔**，`#` 開頭是註解，存檔後重新整理網頁就生效（不用重開遊戲）。

```
# 曲名(或曲目 ID) <Tab> 別名 <Tab> 別名 ...
独サカリ	咬	甘噛
15001	咬
Don't Fight The Music	dftm	donfai	刹那	你不许玩了
```

> 想從內建那份改起：到 GitHub 下載 `src/aliases.txt` 放進去再改。

## 五、遠端分享

把點歌台變成公開連結，發給不在同一個網路的人，對方用手機或電腦瀏覽器打開就能搜歌、點歌、看正在遊玩面板。**不用註冊任何帳號**，預設遊戲一啟動就自動開啟。

### 三條線路

開分享時三條會同時嘗試，**成功的才會列在面板上**，發任一條給對方就行，打不開就換一條。

| 線路 | 連結樣子 | 適合 | 條件 |
|---|---|---|---|
| Cloudflare 通道 | `https://xxxx.trycloudflare.com/?k=…` | 大多數網路 | 中國可能不穩；第一次使用會自動下載 `cloudflared.exe`（約 60MB）到 `Mods\SongRequestMod\` |
| IPv6 直連 | `http://[2408:…]:8790/?k=…` | 中國、行動網路 | 雙方都要有 IPv6（中國手機網路大多有）；光貓 / 路由器要允許 IPv6 連進來 |
| IPv4 直連（NAT 打洞） | `http://1.2.3.4:36475/?k=…` | 只有 IPv4 的網路 | 開分享的電腦要在 NAT1（全錐形）網路；家裡有路由器時會用 UPnP 自動設通訊埠轉發 |

- 直連的兩條不經過任何第三方伺服器
- IPv6 位址或打洞的埠號中途變了，面板上的連結會自動更新（舊連結就失效了，要重新發）
- 用不了的線路，面板會寫原因，例如「本機沒有公網 IPv6」「網路是對稱型 NAT，無法打洞」
- 想知道自己的手機有沒有 IPv6：關掉 Wi-Fi，用行動網路打開 test-ipv6.com

### 怎麼用

1. 本機打開 `http://127.0.0.1:8790/`，右上角「分享連結」面板會自動彈出
2. 按連結旁邊的「複製」，發給對方
3. 不想讓某人繼續點：按「關閉分享」再「開啟分享」。每次開啟都會換新連結和新金鑰，舊連結立刻失效
4. Cloudflare 那條失敗時，可以按「重試 Cloudflare」只重試那一條，已經發出去的直連連結照樣能用
5. 退出遊戲會自動關閉分享

### 安全

- **拿到連結的人都能點歌**。連結裡帶隨機金鑰，別人猜不到，但轉傳出去就等於多了人能點
- 遠端的人不能開關分享，也不能用診斷功能
- 分享面板只有本機和同網路的裝置看得到

### 打不開時

- **Cloudflare 開不起來**：多半是網路擋了 Cloudflare（要能連到外網 7844 埠，UDP 不通時會自動改用 TCP）；或自動下載失敗，可以手動下載 [cloudflared-windows-amd64.exe](https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe)，改名成 `cloudflared.exe` 放到 `Mods\SongRequestMod\`
- **直連連結打不開**：
  - 第一次開分享時 Windows 防火牆可能會跳出詢問，要按「允許」。沒跳出來但連不上的話，到「Windows 安全性 → 防火牆 → 允許應用程式通過防火牆」把遊戲主程式加進去
  - IPv6：光貓或路由器預設可能擋掉從外面連進來的 IPv6，要去管理頁面關掉 IPv6 防火牆或允許入站
  - IPv4 打洞：路由器要開 UPnP；「光貓 + 路由器」兩層的話，光貓最好改成橋接
- 不想用某一條線路：在設定檔把 `Cloudflare隧道`、`IPv6直连`、`NAT打洞` 其中之一改成 `false`

## 六、設定檔 `SongRequestMod.toml`

在 `<遊戲目錄>\SongRequestMod.toml`，第一次啟動自動產生。改完重開遊戲生效。舊的設定檔缺少新選項時會自動補上，原本改過的值會保留。

| 設定 | 預設 | 說明 |
|---|---|---|
| `启用` | `true` | 整個 mod 的開關 |
| `网页` | `true` | 點歌網頁的開關 |
| `网页端口` | `8790` | 網頁的埠號，被別的程式佔用時改這裡 |
| `局域网访问` | `true` | 同網路的手機 / 平板也能打開 |
| `跳转后进难度画面` | `true` | 點歌後自動進難度選擇畫面；`false` = 只移動游標 |
| `封面服务` | `true` | 網頁顯示曲繪封面 |
| `远程分享自动开启` | `true` | 遊戲啟動就自動開分享；`false` = 只在網頁上手動開 |
| `Cloudflare隧道` | `true` | 遠端分享用 Cloudflare 通道；`false` = 不用，也不會下載 cloudflared |
| `IPv6直连` | `true` | 遠端分享用 IPv6 直連 |
| `NAT打洞` | `true` | 遠端分享用 IPv4 直連（NAT 打洞 + UPnP） |
| `崩溃保护` | `false` | 遊戲本身閃退時（例如登入時段位曲目缺失）才打開。會吞掉遊戲的錯誤，平常不要開 |
| `详细日志` | `false` | 日誌輸出詳細過程，排查問題用 |

## 七、常見問題

- **網頁打不開**：先確認日誌有沒有出現「點歌台」那行。出現「啟動點歌台失敗」通常是埠號被佔用，常見原因是上次遊戲沒關乾淨，到工作管理員結束殘留的遊戲程式再重開，或改 `网页端口`
- **手機（同網路）連不上**：多半是 Windows 防火牆擋了，用系統管理員身分開命令提示字元執行一次：
  `netsh advfirewall firewall add rule name="SongRequest" dir=in action=allow protocol=TCP localport=8790`
- **曲庫是 0 首或少很多**：進一次選曲畫面再按「重新整理曲庫」；還是不對的話打開 `http://127.0.0.1:8790/api/selfcheck`，把內容給開發者看
- **點歌或選歌時遊戲卡一下**：打開 `http://127.0.0.1:8790/api/perf`，裡面是各步驟花的時間，把內容給開發者看
- **裝了 mod 之後登入閃退**：先確認是不是最新版；還是會閃退的話，把設定檔 `崩溃保护` 改成 `true` 試試
